## Detailed Troubleshooting

### Step 1: Check Facebook App Settings
1. Ensure your Facebook app is in **Development Mode**
2. Add yourself as a **Test User** if in development mode
3. Verify the app ID matches: `692631938209320`

### Step 2: Verify Android Configuration
Check these files:
- `android/app/src/main/res/values/strings.xml`
- `android/app/src/main/AndroidManifest.xml`
- `android/app/build.gradle`

### Step 3: Test the Implementation
Use the test method in your code:
```dart
await GoogleSignInService.testFacebookLogin();
```

### Step 4: Debug Mode
Run the app in debug mode and check the console logs for detailed error messages.

## Common Issues and Solutions

### Issue 1: Hash Key Mismatch
**Solution**: Add the correct hash key to Facebook app settings

### Issue 2: App Not in Development Mode
**Solution**: Either:
- Put app in development mode and add test users
- Or submit for review to go live

### Issue 3: Package Name Mismatch
**Solution**: Ensure package name in Facebook app matches `com.referaly`

### Issue 4: Missing Permissions
**Solution**: Ensure these permissions are requested:
- `email`
- `public_profile`

## Testing Steps

1. **Clean and rebuild** the project
2. **Uninstall** the app from device
3. **Reinstall** the app
4. **Test Facebook login** with a test account

## Debug Commands

Generate hash keys manually:
```bash
# Debug keystore
keytool -exportcert -alias androiddebugkey -keystore ~/.android/debug.keystore | openssl sha1 -binary | openssl base64

# Release keystore
keytool -exportcert -alias upload -keystore android/referaly.jsk | openssl sha1 -binary | openssl base64
```
